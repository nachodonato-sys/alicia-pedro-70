# Alicia & Pedro · 70

Invitación digital para el cumpleaños de 70 de Alicia y Pedro.

## Incluye
- Cuenta regresiva en vivo
- Fecha, hora y dress code
- Google Maps
- Botón para agregar al calendario
- RSVP conectado a Google Sheets mediante Google Apps Script

## RSVP + Google Sheets
Seguí las instrucciones del archivo `GOOGLE-SHEETS-RSVP.md`.

## Publicar gratis en GitHub Pages
1. Crear un repositorio público.
2. Subir los archivos a la raíz.
3. Settings → Pages.
4. Deploy from a branch.
5. Branch `main`, carpeta `/root`.
